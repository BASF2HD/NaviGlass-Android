# NaviGlass Android project rules

- Keep all Android work in this project; do not modify the original NaviGlassPlayer or PiTunes projects.
- Never publish personal names, private emails, credentials, signing keys, local home paths or real music-library screenshots.
- Agent-created commits use NaviGlass Android Project <naviglass-android@project.invalid> for author and committer.
- Keep this repository private unless the human explicitly approves public visibility.
- No music deletion, tag writing, cloud upload or account requirement. Local library access is read-only.
- Package web libraries locally. Do not add remote scripts or an unrestricted JavaScript interface.
- Test native playback/background behavior on an Android device/emulator before calling a build production-ready.
