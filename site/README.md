# NaviGlass Mobile website

Buildless static GitHub Pages site. index.html, style.css and script.js use only local assets. Public copy has no test branding and does not invent an iOS download.

The images in assets/ are copied from the app's synthetic-library review screenshots, never a personal library. Keep Android download URLs aligned with the current GitHub release. Deploys run on changes to this folder through .github/workflows/pages.yml.

Verified at 1440, 768, 390 and 320 px: responsive layout, local images, portrait/landscape switcher, screenshot zoom/Escape and FAQ. No analytics or third-party scripts/fonts.
